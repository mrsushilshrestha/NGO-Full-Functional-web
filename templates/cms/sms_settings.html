How SMS Notifications Work

When are SMS sent?

  • Form Submission: When someone submits a Volunteer or Membership application
  • Approved: When an admin approves an application
  • Rejected: When an admin rejects an application

What you need:

  • A valid SMS gateway provider (Twilio, Africa's Talking, or your local provider)
  • API Key and optionally API Secret from your provider
  • Sender ID (if required by your provider)

To edit the message content (without coding), go to SMS Message Templates.
